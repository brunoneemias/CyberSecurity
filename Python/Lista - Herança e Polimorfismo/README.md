# 📘 Lista de Exercícios – Polimorfismo em Python

Este repositório contém exercícios individuais de Programação Orientada a Objetos (POO), com foco em **polimorfismo**. Os exemplos foram desenvolvidos em Python para demonstrar como diferentes classes podem compartilhar métodos com comportamentos distintos.


## 📂 Conteúdo dos Exercícios

| Arquivo                   | Tema         | Descrição                                                                 |
|--------------------------|--------------|---------------------------------------------------------------------------|
| `1 - Sistema de animais.py`         | Polimorfismo | Sistema de animais com sons específicos por espécie usando método comum. |
| `2 - Sistema de Documentos.py`      | Polimorfismo | Sistema de documentos com exibição de informações específicas por tipo.  |

---

## 🧠 Conceitos aplicados

- Uso de classes abstratas com `ABC` e `@abstractmethod`
- Implementação de métodos com comportamentos distintos em subclasses
- Listas de objetos com chamadas polimórficas
- Organização modular e reutilização de código
