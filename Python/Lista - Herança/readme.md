# 📘 Lista de Exercícios – Herança em Python

Este repositório contém 4 exercícios individuais de Programação Orientada a Objetos (POO), com foco exclusivo em **herança**. Cada exercício foi desenvolvido em Python como parte da atividade prática da disciplina.

---
## 📂 Conteúdo dos Exercícios

| Arquivo                     | Tema     | Descrição                                                                 |
|----------------------------|----------|---------------------------------------------------------------------------|
| `POO_Heranca_Ingresso.py`  | Herança  | Sistema de ingressos com diferentes tipos e valores.                     |
| `POO_HERANÇA_IMOVEL.py`    | Herança  | Gerenciamento de imóveis com atributos específicos por tipo.             |
| `POO_GestaoFuncionarios.py`| Herança  | Cadastro de funcionários com cargos distintos e métodos personalizados.  |
| `POO_CadastroFatec.py`     | Herança  | Cadastro de pessoas da FATEC (alunos, professores) com estrutura hierárquica. |

---

## 🧠 Conceitos aplicados

- Criação de classes base e derivadas
- Uso de `super()` para herdar atributos e métodos
- Organização de sistemas com hierarquia de classes
- Encapsulamento e reutilização de código
