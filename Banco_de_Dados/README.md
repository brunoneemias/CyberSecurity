# 🗃️ Banco de Dados – Scripts e Projetos SQL

Este diretório contém scripts SQL organizados para fins de estudo, prática e projetos simulados, voltados para segurança e estruturação de dados em ambientes de rede.

## 📁 scripts/

Scripts genéricos para:
- Criação de tabelas
- Inserção de dados
- Consultas básicas e avançadas
- Atualizações e exclusões

## 📁 projetos/

Projetos completos simulando bancos de dados reais:
- `ecommerce.sql`: sistema de loja virtual
- `escola.sql`: gestão de alunos, turmas e notas
- `livraria.sql`: controle de livros, autores e vendas

## 📁 desafios/

Desafios práticos para reforçar conceitos:
- Joins complexos
- Subqueries
- Funções agregadas e filtros

## 🛠️ Requisitos

- MySQL, SQLite ou PostgreSQL
- Ferramentas recomendadas:
  - DBeaver
  - MySQL Workbench
  - SQLite Online

> 💡 *Ideal para quem está estudando modelagem de dados, SQL e segurança em bancos de dados.*
